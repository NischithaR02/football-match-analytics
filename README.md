# Football Match Analytics

## Project Overview

This project analyses professional football positional tracking data to investigate team behaviour and match dynamics using statistical and visual analytics techniques.

The study was completed as part of my MSc Data Science and Analytics dissertation at Cardiff University.

## Objectives

- Analyse team shape and tactical behaviour
- Measure team width, depth and compactness
- Calculate convex hull area to assess spatial coverage
- Compare movement patterns across matches
- Develop interactive visual analytics tools

## Tools and Technologies

- Python
- Pandas
- NumPy
- SciPy
- Matplotlib
- Streamlit

## Key Metrics

- Team Width
- Team Depth
- Team Compactness
- Convex Hull Area
- Team Centroid Position
